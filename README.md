## Описание

Программа реализует задания трёх уровней сложности:

- Базовый уровень: композиция классов Car и Wheel.
- Средний уровень: агрегация классов Team и Player.
- Продвинутый уровень: система управления библиотекой
  с использованием паттерна Singleton.

## Реализованные возможности

- Композиция и агрегация классов.
- Статические поля и методы.
- Паттерн Singleton.
- Добавление, удаление и поиск книг.
- Подсчёт объектов.
- Проверка граничных случаев.
- Безопасное управление памятью.

## Среда разработки

- Язык программирования: C++17
- IDE: Microsoft Visual Studio
